# Peter Mazzey
PhD researcher in Design Engineering at Imperial College London (Dyson School of Design Engineering, EPSRC CDT in Prosthetics and Orthotics).

## PhD thesis code
The code attached to my thesis, Development and validation of an automated computer vision and deep learning design pipeline for mass customised offloading orthotics in diabetic foot ulcer management (Imperial College London, 2026), is held in a private repository and is available on request for academic use. It includes:

- the full pipeline, from image to 3D-printable insole
- the code for the supporting studies (image realism, perspective and back-projection, and sensitivity to camera distance, image resolution and foot rotation)
- the trained CNN weights
